## Rationale
P4451's run-time test with the extensions it combines with: a terminating
contract assertion is enforced under a configured ignore and observe (by
option and by a P3595 configuration file) on each kind of assertion --
`pre`, `post` with and without a result name, `contract_assert`, a member
function, a function template, a lambda, a P3097 virtual function -- and
with a P3098 capture, a P3099 message and a P4283 requires-clause, under
`-fcontracts-p4451` alone, `-fcontracts-p3400` alone and both.

## Compile gap
None.  Pure test addition; it needs every paper it names, the last of
which is `4600-p4283`.
